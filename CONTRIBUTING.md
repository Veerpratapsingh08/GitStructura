# Contributing to GitHub Visualizer

Thank you for your interest in contributing! We welcome all contributions, whether it's fixing a bug, adding a new feature, or improving documentation.

## How to Contribute

1. **Fork the Repository:** Create your own fork of the project.
2. **Clone your Fork:** Clone the fork to your local machine.
3. **Create a Branch:** Create a new branch for your feature or bugfix (`git checkout -b feature/your-feature-name`).
4. **Make Changes:** Make your changes, following our [Project Hygiene](./docs/PROJECT_HYGIENE.md) guidelines.
5. **Commit:** Commit your changes with descriptive messages.
6. **Push:** Push your branch to your fork.
7. **Submit a Pull Request:** Open a Pull Request against our main repository using the provided template.

## Local Development Setup

Please refer to the `README.md` in the root of the project for setup instructions. Ensure you have Node.js and npm installed.

## Code Review

All submissions, including submissions by project members, require review. We use GitHub pull requests for this purpose. Please make sure to fill out the PR template thoroughly.
